# ChrisOS Research Documentation

This repository contains the publication system for the ChrisOS technical documentation.

The site is designed as a long-lived research documentation corpus rather than a marketing site. It combines computing foundations, the architecture and implementation of ChrisOS from the `main` branch, a generated source atlas, specifications, diagrams, revision metadata, and low-context workflows for AI agents.

## Design constraints

1. Markdown is the source of authored documentation.
2. The frontend is deliberately small: MkDocs Core, a custom Jinja theme, one stylesheet and one small JavaScript file.
3. Generated facts are not written by AI: repository inventory, hashes, source atlas, current revision and stale-page reports are generated by scripts.
4. Theory, architecture, implementation, validation and roadmap are distinct.
5. Pages declare their source dependencies in frontmatter.
6. Agents update only affected pages.
7. English and Brazilian Portuguese are first-class trees.
8. No exercises and no conversational instructional prose.

## Local build

```bash
git clone https://github.com/christianrss/chrisos_site.git
cd chrisos_site
git clone --depth=200 https://github.com/christianrss/ChrisOS.git .source
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/build_all.py --source .source --docs docs
mkdocs serve
```

## Low-cost agent workflow

```bash
python scripts/context_pack.py docs/en/05-memory/virtual-memory.md --source .source
```

The resulting `.context/<page-id>/` contains only the page, declared source files, relevant Git diff, metadata and instructions. See `AGENTS.md`.

## Deployment

Every push to `main` runs the deterministic documentation pipeline and deploys GitHub Pages.
